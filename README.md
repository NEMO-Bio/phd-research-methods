# 博士研究的工作方法与准则

主成品分为三册：`index.html`、`02-four-core-trainings.html`、`03-execution-and-boundaries.html`。网页、源稿、构建工具与更新记录均纳入 Git 版本控制；用于内部核验的 PDF 不公开上传。

三册可由左侧目录切换，也可在文末前后翻阅。全套包含 25 节正文、1 张保留图、13 张表和 25 项已引用来源；表格说明移到表格外，正文、表格与图使用同一内容宽度。

## 核心结论

AI 大幅降低了搜索、解释、初稿和代码脚手架的成本，却没有降低研究者对问题、证据与结论的责任。博士训练的稀缺环节因此向规定问题、真正理解、做出判断、产出证据、公开表达和经受追问移动。

本手册借用语言学习中常见的“听说读写”分类，归纳博士阶段的四类核心研究能力；它也适用于其他科研学习阶段，尤其面向 AI 已进入检索、分析与写作流程的研究生。

四类能力不是彼此孤立的技能：

- 听：现场到问题模型
- 说：内部模型到共同理解
- 读：论文到证据机器
- 写：过程到可积累对象

AI 可贯穿四者，但研究者必须对来源、复现、理解和答辩负责。

## 项目结构

- `idea.md`：用户原始想法与研究任务
- `design.md`：核心 thesis、反例、证据计划与边界
- `outline.md`：25 节叙事结构
- `literature/`：22 份当前引用的机器可读全文
- `literature/README.md`：三轮检索记录、文献注释与纠错
- `literature/NEEDED.md`：调查过但因全文条件不足而未引用的来源
- `analysis/framework_model.py`：生成结构计数和 5 张 SVG 图
- `figures/`：代码生成图表
- `src/`：分段 HTML 源稿
- `tools/`：文献下载、引用编号、构建与质量检查工具

## 复现成品

在本目录运行：

```bash
python3 analysis/framework_model.py
python3 tools/renumber.py src
python3 tools/build_volumes.py
```

当前质量检查结果：25 项参考文献均在三册正文引用，22 个 PDF 链接全部存在，25 个章节与 1 张保留图结构完整；三册之间的链接、局部锚点与引用跳转均自动核对。
